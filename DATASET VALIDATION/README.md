## 🔬 Certified Validation Thresholds & Guarantees

| Validation Check | Scientific Metric | Certified Pass Standard |
|---|---|:---:|
| **CPCB Ground Sensors** | $\text{NO}_2, \text{O}_3, \text{PM}_{2.5}, \text{PM}_{10}, \text{SO}_2, \text{CO}, \text{NH}_3$ bounds | **$100\%$ Finite & Non-Negative** |
| **ERA5 Meteorology** | Temp ($-10^\circ\text{C}$ to $55^\circ\text{C}$), Pressure ($900$ to $1050\text{ hPa}$), $\text{BLH} > 0$ | **$100\%$ Physical Consistency** |
| **Sentinel-5P Satellite** | QA Value $\ge 0.5$, valid pixel counts, non-negative column densities | **$100\%$ QA Compliant** |
| **Geospatial Buffers** | Distance to road $\ge 0\text{m}$, Road length $1\text{km}/3\text{km} > 0\text{m}$, Land use sum $\le 1.0$ | **$100\%$ Topology Verified** |
| **Temporal Leakage** | Feature timestamp $< \text{Target timestamp}$ (zero lookahead) | **$0.0\%$ Future Leakage** |
| **Timestamp Continuity** | Jan 1, 2023 00:00 UTC to Dec 31, 2025 23:00 UTC (10 stations $\times$ 26,304h) | **Exactly 263,040 Rows (0 Gaps)** |
